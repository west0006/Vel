# 像素猫咪动画 - 设计文档（AI 生图专用版）

> 版本：2.1  
> 更新日期：2026-06-18  
> 用途：本文件用于指导 **AI 图像生成工具（如 Midjourney、Stable Diffusion）** 逐帧生成像素风格猫咪动画序列，也供美术人员参考。

---

## 1. 项目概述

为扁平极简 UI 应用设计一只动态的像素猫咪角色，通过不同动作表达情感，增强交互趣味。  
所有动画帧均为 **像素风格（Pixel Art）**，边缘清晰，无抗锯齿，背景透明。

---

## 2. 统一配色方案（固定色值）

| 角色 | 色值（HEX） | 用途 |
|------|------------|------|
| 主色（暖橙） | `#FF8C42` | 身体主色 |
| 辅助色（暖黄） | `#FFD166` | 面部、腹部高光 |
| 米白 | `#FFF8F0` | 眼白、嘴部、高光 |
| 深棕（描边） | `#5C3D2E` | 轮廓线、瞳孔、鼻头 |
| 肉粉 | `#FFB6C1` | 耳朵内部、爪子肉垫 |
| 深橙（阴影） | `#CC6A2F` | 身体暗部、尾巴下方 |

**重要**：提供的原始 SVG 素材为灰色调，**仅作像素布局参考**。实际生成的每一帧必须使用上述暖色系。  
已提供 `recolor_svg.py` 一键换色脚本，可将灰图转换为暖色（但 AI 生成时最好直接输出暖色，避免二次处理）。

---

## 3. 动画技术规格

| 属性 | 值 |
|------|-----|
| **画布尺寸** | 128×128 像素（正方形） |
| **显示缩放** | 2 倍 → 256×256（采用最近邻插值，保持锐利） |
| **帧率** | 10 fps（100ms/帧）；睡眠/毛团状态可降至 5fps（200ms/帧） |
| **背景** | **完全透明**（PNG-24，无任何背景色块） |
| **文件格式** | 独立 PNG 序列 |
| **文件命名** | `{state}_{两位序号}.png`，如 `idle_01.png` |
| **目录结构** | `ui/resources/pet_frames/{state}/`（按状态分文件夹） |

---

## 4. 状态与动作定义（核心 — AI 生成指令）

每个状态包含 **帧数**、**循环方式** 和 **每一帧的详细姿态描述**。  
**请为每一帧生成一张独立的 128×128 像素图**，严格遵循配色，背景透明。

---

### 4.1 待机 idle（6 帧，循环播放）

猫咪端正坐着，尾巴左右缓慢摆动，每 4 次循环眨一次眼（本设计将眨眼放在第 4 帧）。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| idle_01 | 坐姿端正，尾巴自然垂于右侧，稍微向左摆动（约 30°），双眼睁开，目视前方。 |
| idle_02 | 尾巴继续向左摆动至最大角度（约 60°），身体保持不动，双眼睁开。 |
| idle_03 | 尾巴回正（指向正下方），双眼仍睁开。 |
| idle_04 | **尾巴保持回正，双眼闭合**（眨眼帧），其余姿势不变。 |
| idle_05 | 尾巴向右摆动至约 30°，双眼睁开。 |
| idle_06 | 尾巴向右摆动至最大角度（约 60°），双眼睁开。完成后回到 idle_01。 |

---

### 4.2 唤醒 wake（8 帧，单次播放，结束后回到 idle）

点击猫咪或唤醒词触发，表现伸懒腰并端正坐好的过程。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| wake_01 | 趴卧姿势，前爪向前伸展，身体压得很低，嘴巴微微张开（打哈欠），眼睛半闭。 |
| wake_02 | 前爪撑地，弓起背部（像猫伸懒腰），后腿蹬直，尾巴向上翘起。 |
| wake_03 | 身体继续抬高，后腿逐渐站直，前爪仍撑地，头部上扬。 |
| wake_04 | 完全站立，四肢着地，身体呈桥形，头部向下低垂（伸展脊柱）。 |
| wake_05 | 身体开始落下，前爪收回，准备转为坐姿，尾巴微微晃动。 |
| wake_06 | 已经坐好，但身体略显松散，眼睛半睁，尾巴尚未完全收拢。 |
| wake_07 | 端正坐姿，尾巴开始向身体前方绕去，眼睛完全睁开。 |
| wake_08 | **最终坐姿**，尾巴整齐地绕到前爪旁，姿态与 idle_01 几乎一致，为切换做准备。 |

---

### 4.3 提醒 alert（6 帧，单次播放，不可打断）

收到通知时，猫咪用右爪向下轻拍屏幕，**重复两次**（拍击+抬起为一组，共两组）。  
注意：每一下拍击应表现出“用力”的重量感。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| alert_01 | 坐姿，右爪高高抬起（准备拍击），身体略微前倾，尾巴竖起。 |
| alert_02 | **第一次拍击**：右爪用力向下拍落，触及地面（或虚拟平面），身体随之下沉。 |
| alert_03 | 右爪收回，重新抬起至半空（准备第二次拍击），身体恢复些。 |
| alert_04 | **第二次拍击**：右爪再次用力拍下，触及地面。 |
| alert_05 | 拍击后右爪抬起，但未完全收回，身体保持略前倾，尾巴抖动。 |
| alert_06 | **最终收回**：右爪完全放下，恢复端正坐姿，与 idle_01 姿态相同（切换回 idle）。 |

---

### 4.4 开心 happy（4 帧，循环 5 次后回 idle）

用户完成提醒或被夸奖时表现，眼睛眯成缝，身体轻微上下弹跳，尾巴尖快速颤动。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| happy_01 | 坐姿，眼睛眯成细缝（^_^），身体微微下沉，尾巴尖向上翘起并抖动。 |
| happy_02 | 身体向上弹跳，离开地面，前爪微微抬起，尾巴尖颤动更剧烈。 |
| happy_03 | 身体到达最高点，耳朵竖直，表情愉悦，尾巴尖呈波浪状抖动。 |
| happy_04 | 落回地面，恢复坐姿，但尾巴尖依然快速抖动，眼睛仍眯着。之后回到 happy_01 继续循环，满 5 次后切 idle。 |

---

### 4.5 失落 sad（4 帧，循环 5 次后回 idle）

用户拒绝提醒时表现，猫咪转身背对用户，但耳朵仍朝向用户，表达傲娇。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| sad_01 | 身体开始向右侧转动，头部仍回望用户，耳朵轻微下垂。 |
| sad_02 | 身体转至 45°，仅剩头部朝前，耳朵继续下垂。 |
| sad_03 | **完全背对**用户（只显示背部），耳朵耷拉至最低。 |
| sad_04 | 保持背影，但耳朵微微抬起并朝向用户方向（表示仍在乎），身体不动。之后循环，满 5 次回 idle。 |

---

### 4.6 思考 thinking（3 帧，循环播放）

用户输入时或等待响应时触发，猫咪低头用爪子托下巴，耳朵转动。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| think_01 | 低头，右爪抬起轻轻触碰下巴，眼睛斜向上看（思考状）。 |
| think_02 | 右爪放下，耳朵向左转动（听动静）。 |
| think_03 | 右爪再次抬起触碰下巴，耳朵向右转动。循环。 |

---

### 4.7 睡眠 sleep（2 帧，循环播放，低帧率 5fps）

长时间无操作（如 60 秒）进入，身体趴下闭眼，缓慢呼吸。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| sleep_01 | 趴卧，身体舒展，双眼闭合，腹部微微鼓起（吸气）。 |
| sleep_02 | 趴卧，腹部稍微回落（呼气），其余不变。循环。 |

---

### 4.8 毛团 collapsed（2 帧，循环播放，低帧率 5fps）

贴边隐藏时，猫咪缩成圆润毛球，仅露耳朵和尾巴尖。

| 帧号 | 动作描述（给 AI 的提示词） |
|------|---------------------------|
| collapsed_01 | 缩成紧凑的圆球，耳朵和尾巴尖突出，球体略微收缩。 |
| collapsed_02 | 球体微微膨胀（呼吸），耳朵和尾巴尖随之移动少许。循环。 |

---

## 5. 状态切换逻辑（给开发参考）

- **默认状态**：`idle`
- **唤醒**：点击猫咪 → 播放 `wake`（单次）→ 自动转 `idle`
- **提醒**：收到通知 → 立即播放 `alert`（单次，**不可被中断**）→ 自动转 `idle`
- **开心/失落**：用户操作后 → 播放对应状态（循环 5 次，约 2 秒）→ 自动转 `idle`
- **思考**：用户输入时 → 切换到 `thinking`（循环），输入结束 → 回 `idle`
- **睡眠**：无操作超时 → `sleep`（循环），点击或通知 → 先 `wake` 再切相应状态
- **毛团**：贴边隐藏 → `collapsed`（循环），拖出或点击 → 回到 `idle`

所有状态切换应保证 **最后一帧姿态与 idle_01 尽量一致**，以保持视觉连贯。

## 6. 给 AI 生图的提示词模板（Midjourney 示例）

为了确保一致性，请使用以下 **统一前缀 + 每帧专属描述**：

### 基础模板（固定部分）
```
pixel art, a cute orange cat, 64x64 pixels, solid colors, no anti-aliasing, white background, flat shading, warm orange (#FF8C42) and yellow (#FFD166), dark brown outlines (#5C3D2E), transparent background, 8-bit game sprite --v 6.0 --style raw --seed 123456
```

### 每帧描述替换 `[具体动作]`
例如：  
**idle_01** 的完整提示词：
```
pixel art, a cute orange cat, sitting upright, tail slightly to the left, eyes open, facing forward, 64x64 pixels, solid colors, no anti-aliasing, white background, flat shading, warm orange and yellow, dark brown outlines, transparent background, 8-bit game sprite --v 6.0 --style raw --seed 123456
```

**重要**：  
- 所有帧必须使用 **相同的 `--seed` 值**（如 123456）以确保角色一致。  
- 建议使用 `--v 6.0` 或更高版本。  
- 若生成结果像素感不足，可增加 `--s 250` 降低风格化。
