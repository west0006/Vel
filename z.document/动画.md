## 像素猫咪动画系统设计

### 1. 整体规格

| 属性 | 值 |
|------|-----|
| **风格** | 像素画（Pixel Art），清晰边缘，无抗锯齿 |
| **配色** | 主色：**暖橙 `#FF8C42`**，辅助：**暖黄 `#FFD166`**，**米白 `#FFF8F0`**，深色描边：**深棕 `#5C3D2E`** |
| **尺寸** | 猫咪本体 **128×128 px**（内部绘制区域），显示缩放为 **256×256**（整数倍放大，保证像素锐利） |
| **帧率** | 8-10 fps（像素动画常见帧率） |
| **格式** | 序列帧 PNG（背景透明），统一放于 `ui/resources/pet_frames/` |

### 2. 状态与动作对应

我们定义5种核心状态，每种状态对应一组像素帧循环。

| 状态 | 触发条件 | 动作描述 | 帧数 | 循环 |
|------|---------|---------|------|------|
| **待机 idle** | 无事发生时 | 猫咪坐着，尾巴缓慢左右摇摆，偶尔眨眼睛 | 6帧（尾巴摆1-2-3-2-1+眨眼帧） | 循环 |
| **唤醒 wake** | 点击或唤醒词触发 | 猫咪伸懒腰，然后端正坐好，尾巴绕到前面 | 6帧（非循环，播放完转入idle） | 单次 |
| **提醒 alert** | 通知触发 | 猫咪用爪子轻轻敲击屏幕（向下），重复两次 | 4帧（拍击+收回）×2 | 单次（可重复2遍） |
| **开心 happy** | 用户完成提醒或被夸 | 眼睛眯成缝，尾巴尖快速颤动，身体微微上跳 | 4帧 | 循环2秒后回idle |
| **失落 sad** | 用户拒绝提醒 | 转过身去，只留背影，耳朵耷拉，但耳朵仍朝向用户（表现傲娇） | 4帧（转身+耳朵动） | 循环2秒后回idle |

**额外状态**：
- **毛团 collapsed**：贴边隐藏时，猫咪缩成一个圆滚滚的像素毛球（耳朵和尾巴尖露出），尺寸改为64×64，显示时直接缩放此静态图（加轻微呼吸起伏2帧）。

### 3. 美术资源需求清单

所有帧以独立PNG提供，文件名规则：`{state}_{frame}.png`。

```
ui/resources/pet_frames/
├── idle_01.png ~ idle_06.png
├── wake_01.png ~ wake_06.png
├── alert_01.png ~ alert_04.png
├── happy_01.png ~ happy_04.png
├── sad_01.png ~ sad_04.png
├── collapsed_01.png ~ collapsed_02.png
```

**建议**：可以先用简单的像素形状（圆形+三角耳朵+尾巴线条）自己画，或者用免费像素猫素材修改颜色（需确认为橘色暖黄）。

### 4. 技术实现（PyQt5 动画控制器）

我们需要一个独立的 `AnimationController` 类，管理当前状态和帧切换。

**逻辑**：
- 使用 `QTimer` 按帧间隔（100-125ms）驱动。
- 所有帧图预先加载为 `QPixmap` 列表缓存。
- 提供 `set_state(state)` 方法，切换状态时：  
  1. 中断当前循环。  
  2. 载入新状态帧列表。  
  3. 如果新状态是单次播放，播放完自动回到 `idle`；否则循环。

**像素放大渲染**：  
由于原始帧是128×128，我们用 `QPixmap.scaled(256, 256, Qt.KeepAspectRatio, Qt.FastTransformation)` 确保像素边缘不模糊。`FastTransformation` 保留像素硬边。

**代码示意**（关键部分，非完整文件）：

```python
class AnimationController(QObject):
    state_changed = pyqtSignal(str)

    def __init__(self, parent=None):
        super().__init__(parent)
        self.frames = {}           # state -> list of QPixmap
        self.current_state = "idle"
        self.current_frame_idx = 0
        self.timer = QTimer(self)
        self.timer.timeout.connect(self.next_frame)
        self.loop = True
        self.after_finish_state = "idle"

    def load_frames(self, state, file_list):
        frames = []
        for f in file_list:
            pix = QPixmap(f)
            if not pix.isNull():
                # 放大2倍保留像素锐利
                pix = pix.scaled(128*2, 128*2, Qt.KeepAspectRatio, Qt.FastTransformation)
                frames.append(pix)
        self.frames[state] = frames

    def set_state(self, state, loop=True, after_finish="idle"):
        if state not in self.frames:
            return
        self.timer.stop()
        self.current_state = state
        self.current_frame_idx = 0
        self.loop = loop
        self.after_finish_state = after_finish
        self.timer.start(100)  # 10 fps
        self.state_changed.emit(state)

    def next_frame(self):
        frames = self.frames[self.current_state]
        if self.current_frame_idx >= len(frames):
            if self.loop:
                self.current_frame_idx = 0
            else:
                self.timer.stop()
                self.set_state(self.after_finish_state, loop=True)
                return
        # 更新到UI（通过信号）
        self.parent().update_pixmap(frames[self.current_frame_idx])
        self.current_frame_idx += 1
```

在 `FloatingPet` 中集成：
- 替换 `QLabel` 显示的 Pixmap 为动画控制器提供的当前帧。
- 状态切换时机：
  - `idle`：初始化后默认。
  - `wake`：点击猫咪后（`toggle_chat` 之前调用）。
  - `alert`：通知事件（`bus.subscribe_ui('SCHEDULE_ALERT', ...)` 触发）。
  - `happy`/`sad`：用户操作反馈（如接受推荐/拒绝提醒）。

### 5. 扁平UI与像素猫的协调

- 猫周围保留足够负空间，不添加UI元素的阴影或圆角框。
- 对话气泡、通知等仍然是扁平圆角线条，但里面的猫咪小头像（若有）也用像素版本。
