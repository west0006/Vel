## 二、主推：MeaPet —— 与本项目近乎一一对应

作者自评"非常不完善"，但对学习恰好：**没有过度抽象，机制可读、可抄**。

### 2.1 对应关系

| Vel 的待办 | MeaPet 对应文件 | 机制要点 |
|---|---|---|
| E5 流式对话 | `meapet/direct/conversation.py`（390 行） | `stream_turn()` 异步迭代器 + `cancel(turn_id)` 取消；后端切换时取消在途生成 |
| LLM 输出驱动情绪/动作 | `meapet/conversation/output_protocol.py`（391 行） | `<MEA_PET_SEGMENT><DISPLAY>…</DISPLAY><META>{json}</META></MEA_PET_SEGMENT>` + `<MEA_PET_DONE/>`；`MeaPetOutputStreamParser.feed()` 增量解析；`requires_repair()` 字段缺失自动补一轮修复；三级降级（protocol → legacy → plain） |
| E11 点击穿透 | `meapet/desktop/click_through.py`（1159 行，**Win32 段仅约 100 行**） | `GWL_EXSTYLE` 加 `WS_EX_LAYERED\|WS_EX_TRANSPARENT`；`GetAsyncKeyState(VK_RBUTTON)` 轮询右键；`set_shape_region(rects)` 动态命中区；源码注释点明工业标准是 `WM_NCHITTEST` + `HTTRANSPARENT` |
| P2-3 抚摸反馈 | `meapet/desktop/interaction.py`（277 行） | `_on_head_patted` / `_on_zone_triggered(zone)` 分区反馈、`_show_bubble` 气泡栈、`_idle_action` 空闲动作、互动语音缓存 |
| 记忆 / 好感度 | `meapet/memory/db.py` | SQLite 记忆 + 好感度 |
| 打包 | `scripts/build_windows.ps1` + `MeaPet.spec` | PyInstaller **onedir**（与 `build.spec` 同路子） |

### 2.2 阅读建议

只读 Windows 相关，跳过它的 Linux 分支（`click_through.py` 里 Wayland/X11 占了大半篇幅，Vel 用不到）。

## 三、动画与交互范本：DyberPet（PySide6）

PySide6 与 PyQt5 API 几乎同族，**读它的 Qt 代码可直接翻译回 PyQt5**。

| 文件 | 内容 |
|---|---|
| `DyberPet/DyberPet.py`（2085 行） | `PetWidget`：手写 `mousePress/Move/ReleaseEvent` 拖拽 · `limit_in_screen()` 边界 · `ontop_update()` 置顶守护 · `patpat()` 抚摸 · `runAnimation/runInteraction/runScheduler/_mightEventTrigger` 四条独立行为循环 · `follow_mouse_act()` 视线跟随 · `_load_custom_anim()` 自定义动画 |
| `DyberPet/bubbleManager.py`（210 行） | 气泡类型配置 + 权重随机 + `USERTAG` 昵称替换 + 按 HP/FV 分档触发（详见 `dev/方案-动画与气泡系统设计笔记.md`） |
| `res/role/*/pet_conf.json` | 动画名 / 锚点 / 缩放 / `random_act` 权重表 —— **数据驱动，换角色只换 JSON** |
| `DyberPet/HideDock/HideDock.py` | 贴边隐藏 |

**限制**：GPL-3.0（**学设计、不抄代码**）；且 **LLM 模块未开源**（仓库只开源到 v0.6.7），别指望从它学 LLM。

## 四、LLM 机制：Open-LLM-VTuber（MIT）

`prompts/utils/` 下的**小文件价值最高**，可改造成 Qwen2.5 的提示词：

| 文件 | 作用 |
|---|---|
| `live2d_expression_prompt.txt` | 教模型在回复中内联 `[expression]` 关键字驱动表情；含示例与"不得使用列表外关键字"约束 |
| `think_tag_prompt.txt` | `<think>内心 OS</think>` 与台词分离 |
| `speakable_prompt.txt` | 数字/日期/货币的可朗读化规则（为 TTS 铺路） |
| `proactive_speak_prompt.txt` | AI 主动搭话的触发提示词 |
| `src/open_llm_vtuber/utils/sentence_divider.py`（608 行） | **标签状态机**（`TagState`/`TagInfo`）+ 流式按句切分，使"边生成边 TTS"不切碎标签 |
