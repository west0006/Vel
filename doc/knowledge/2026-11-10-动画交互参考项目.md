## 三、第二梯队：动画状态机（Vel 现为 8 个情绪 + QTimer 硬切）

### 3. `pet4claude`（Codeberg，**PySide6**）★ 设计最佳

三层状态机（模块 docstring 中直接画出）：

```
drag_state    — 拖拽时置位
oneshot_state — 单次覆盖（挥手 / 跳跃 / 失败 / 审查）
base_stack    — 循环区间栈，栈顶生效；栈底永远是 (None, "idle")
```

事件「开启区间」（push）/「关闭区间」（pop 到匹配项）；单次动作播完自动回落 `base_stack[-1]`。
另用**逐帧时长数组**而非固定 FPS（`idle: [280,110,110,140,140,320]`），定时器 single-shot，
每帧后用 `current_duration_ms()` 重排。

> PySide6 与 PyQt5 同族，可直接翻译进 `ui/floating_pet.py`。

### 4. `Bolt-Pet`（自建 Git，**PySide6**）

两个可直接抄的工程细节：

- **距离驱动的行走循环**：按「移动了多少像素」推进帧（`_WALK_PIXELS_PER_FRAME = 13.0`），
  而非按动画时钟 → 速度与帧率不一致时不会「脚底打滑」；
- **alpha 派生输入掩码**：`QRegion(pixmap.mask())` + `setMask()`，且**只在 `pixmap.cacheKey()`
  变化时重建** —— 比 Vel 现有 `_is_click_on_body`（每次点击 `toImage()` + `pixelColor`）更优；
- 移动定时器（约 30fps）与精灵定时器**解耦**，互不驱动。

### 5. `77wliNd/aemeath_withclaude`（**191★**，Rust + Tauri，MIT）

15 种像素动画 + 状态优先级仲裁。最值得抄的是**「工具间保持最小停留时间，防止动画闪烁」**
—— Vel 的「闪」很大程度就是缺这个。

### 6. `chrislitality-svg/PixelPal`（TypeScript，MIT，4★）

**13 状态 FSM + 合法转移图**（transitions 显式限制可转移对），上层套**行为树 5 级优先级**
（Emergency → Physiological → Entertainment → Random → Default）+ `BehaviorRateLimiter` 防抖。
**合法转移图**正是 Vel 缺的：目前任意情绪都能切到任意情绪。

### 7. `LorisYounger/VPet`（**7206★**，C#/WPF，Apache-2.0，2026-11-07 仍更新）

**ABC 三段式**动画（`A_Start → B_Loop → C_End`）+ **用资源命名承载状态机元数据**
（`happy/touch_head/pet_a_125.png` 即编码了状态/动作/动画名/帧时长）。
⚠️ 代码 Apache-2.0，但**自带动画素材另有版权**（商用需署名、不得售卖）。

## 六、建议的阅读顺序

1. `zhizhiji-shimeji/gen_frames.py` —— 判断「单图生成帧序列」能否产出你要的猫（**唯一能根治帧不一致的路线，且无美术工作量**）；
2. `pet4claude` 的 `pet_daemon.py` docstring + `_active_animation` / `_close_intervals` —— 三层状态机可直接搬进 `floating_pet.py`；
3. `Bolt-Pet` 的两个细节：距离驱动行走、alpha 掩码（顺带解决 `_is_click_on_body` 的性能问题）；
4. 其余按需看设计，不建议花时间读跨语言实现细节。
