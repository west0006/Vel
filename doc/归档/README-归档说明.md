## 一、归档规则

1. 文档被新版本整体取代时，**移入本目录**，不在原位置保留副本。
2. 移入时必须在本文件登记：**版本链**（谁取代谁）、**取代原因**、**现行文档在哪**。
3. 归档件正文开头加标注：`> ⚠️ 已作废（日期）—— 已被 <现行文档> 取代，不要据以开发。`
