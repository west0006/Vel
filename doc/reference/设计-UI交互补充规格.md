## 设计-UI交互补充规格.md（完善版）

### UI设计补充规格（扁平极简版 v1.1）

> 本文档是对《智能AI桌宠（PC端）项目详细设计文档》v1.1 的交互设计补充。
> 与主文档 7.1~7.6 节配合使用，本补充规格优先级更高。

---

#### 1. 全局风格定义

- **风格基调**：扁平化，弱投影（仅悬浮窗和面板使用），无渐变，谨慎使用半透明。
- **图标**：全部采用线性描边图标（Feather / Lucide 风格），搭配 Emoji 风格小插图用于情绪表达。
- **线框**：1px 实色描边，圆角 `6-10px` 柔和过渡，最大 `12px`（面板级）。
- **字体**：
  - 中文正文：`"Microsoft YaHei"`，标题加粗（`font-weight: bold`）。
  - 数字/英文/代码：`"Consolas"` 或系统等宽。
  - 最小字号 `12px`，禁用 `10px` 以下字号（无障碍）。
  - 禁止手写/艺术字体。
- **配色**（暖橙扁平系，高对比度）：

| 语义 | 色值 | 用途 |
|------|------|------|
| 主背景 | `#FFFFFF` | 窗口、面板底色 |
| 卡片/气泡背景 | `#FAFAFA` | 消息气泡、卡片 |
| 主文字 | `#1E1E1E` | 标题、正文 |
| 次要文字 | `#5A5A5A` | 辅助说明、时间戳 |
| 提示/占位文字 | `#9E9E9E` | placeholder、禁用文字 |
| 边框 | `#E0E0E0` | 输入框、卡片、分割线 |
| 强调色 | `#FF6B35` | 主按钮填充、链接、左边框、通知边框 |
| 强调色-hover | `#E55A2B` | 按钮 hover |
| 强调色-pressed | `#CC4F26` | 按钮按下 |
| 危险色 | `#D32F2F` | 删除、清除按钮 |
| 成功色 | `#2E7D32` | 完成确认 |
| 用户消息气泡 | `#EDEDED` | 用户消息背景 |
| 桌宠消息左边框 | `3px solid #FF6B35` | 桌宠消息标识 |
| 阴影 | `0 2px 8px rgba(0,0,0,0.08)` | 仅悬浮窗与模态面板 |

#### 4. 动画参数

所有动画使用 `QPropertyAnimation`，不引入第三方动画库。

| 动画 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 气泡弹出 | 200ms | `easeOutCubic` | `geometry` 从中心缩放到目标 |
| 气泡收起 | 150ms | `easeInCubic` | 反方向缩放到中心 |
| 毛团聚拢 | 200ms | `easeInOutCubic` | 贴边时缩小为毛团圆 |
| 毛团展开 | 200ms | `easeInOutCubic` | 鼠标悬浮恢复 |
| 待机表情切换 | 250ms | 淡入淡出（`windowOpacity`） | QTimer 在帧切换间插入透明度过渡 |
| 通知出现 | 150ms | `easeOutCubic` | 从右上方滑入 + 淡入 |
| 通知消失 | 150ms | `easeInCubic` | 向右上方滑出 + 淡出 |
| 设置面板打开 | 0ms | 无 | 模态窗口直接显示 |
| 引导向导步骤切换 | 200ms | `easeInOutCubic` | stackedWidget 水平滑动 |

#### 6. 快速交互设计

##### 6.1 对话气泡

- **定位**：猫咪头顶正上方，左右居中。气泡边缘触碰屏幕边界时自动翻转（底部在上）。
- **跟随行为**：猫拖动时气泡**不跟着移动**，气泡保持原位。猫再次被点击时气泡重新定位。
- **关闭方式**：点击气泡外部任意位置关闭（通过 `eventFilter` 监听全局点击）；点击气泡 `✕` 按钮关闭；按 `Esc` 关闭。
- **消息样式**：
  - **用户消息**：右对齐，背景 `#EDEDED`，圆角 `10px`，最大宽度 `260px`。
  - **桌宠消息**：左对齐，背景 `#FFFFFF`，左边框 `3px solid #FF6B35`，圆角 `10px`，最大宽度 `260px`。
  - **无头像**。
  - **时间戳**：每 5 分钟显示一次时间分隔线（`-- 14:30 --`），字体 `11px #9E9E9E`。
- **输入区**：底部固定，单行自动扩展至 3 行后出现滚动条。placeholder "给 Vel 发消息..." 颜色 `#9E9E9E`。
- **思考状态**：LLM 推理时显示三个跳动圆点动画（`● ○ ○` → `○ ● ○` → `○ ○ ●`），替代静态文字"正在思考"。

##### 6.2 通知气泡

- **定位**：屏幕右上角，距顶部 `50px`，距右侧 `20px`。不跟随猫位置。
- **按钮样式**：主操作按钮填充 `#FF6B35` 文字白色；次要按钮线框 `#E0E0E0`；第三按钮文字无框。
- **排队规则**：
  - 新通知到达时，若当前有通知正在显示：
    - **新通知优先级更高**：立即打断当前通知（当前通知视为 skip），显示新通知。
    - **优先级相同或更低**：加入队列末尾。
  - 被打断的通知**不视为 ignore**——饮食推荐被打断不进入1小时冷却，仅进入队列稍后显示。
  - 优先级数值：`2=强提醒(日程到期) > 1=预警 > 0=健康提醒`。
- **自动消失**：默认 8 秒后自动消失，无操作视为 skip。

##### 6.3 设置面板

- 左侧导航：图标 + 文字，当前项图标填充 `#FF6B35`，文字加粗；非当前项图标 `#5A5A5A`，文字正常。
- 导航宽度 `150px`，背景 `#FAFAFA`，右边框 `1px solid #E0E0E0`。
- 右侧内容区域 `550px`，顶部留白 `16px`，左右 `20px`。
- 保存操作：所有设置**即时生效**，无需点"保存"按钮（底部保留"恢复默认"按钮）。

##### 6.4 健康看板

- 饮水进度：`QProgressBar`，`#FF6B35` 填充，文字显示 `1250/2000ml (62.5%)`。
- 久坐计时：数字 + 单位 `42分钟`，超阈值时数字变 `#D32F2F`。
- 情绪趋势：`😊 → 😐 → 😞` 简标，横向排列，当前项放大。
- 不使用折线图或 canvas 绘制。

##### 6.5 系统托盘菜单

```text
┌──────────────────┐
│ 💬 对话          │
│ 📋 今日日程      │
│ ──────────────── │
│ ⏸ 暂停所有提醒   │  ← 新增，切换项
│ ⏸ 免打扰1小时   │
│ ⏸ 免打扰至明早   │
│ ──────────────── │
│ ⚙ 设置          │
│ ℹ 关于          │
│ ❌ 退出          │
└──────────────────┘
```

- **暂停所有提醒**：切换项，选中时显示 `▶ 恢复所有提醒`，暂停饮水/久坐/作息全部健康调度器。

##### 6.6 引导向导

- 模态窗口 `600x450px`，背景 `#FFFFFF`，无边框装饰。
- 步骤指示器：顶部 5 个圆点 `○ ○ ○ ○ ○`，当前步骤填充 `#FF6B35`，已完成步骤填充 `#E0E0E0`。
- 可完全跳过（每步有"跳过"按钮，最后一步为"开始使用"）。
- 完成后不播放额外动画，直接进入桌面悬浮状态。

##### 6.7 空状态 / 加载中 / 错误状态

| 场景 | 视觉表现 |
|------|---------|
| 对话历史为空 | 猫咪撑头表情 `🐱` + 文字 "还没有聊天记录，点击我说句话吧~" |
| LLM 模型加载中 | 托盘图标脉冲动画（透明度 40%↔100% 循环），悬浮提示 "Vel 正在醒来..." |
| LLM 降级模式 | 托盘图标灰度 40%，悬浮提示 "AI 降级模式"，对话气泡中回复带 `⚠️` 前缀 |
| 搜索全部失败 | 回复 "搜索暂不可用 😿"，不显示错误详情 |
| 网络断开 | 不弹窗打断用户，仅在日志中记录 |
| 数据库损坏 | 启动时弹窗 "数据库异常，已恢复到最近备份/新库"，然后继续启动 |

#### 7. 图标资源规格

##### 7.1 命名映射

所有图标使用 SVG 文件从 `ui/resources/icons/` 加载，通过 `QIcon` 渲染。

```python
ICON_MAP: dict[str, str] = {
    # 导航
    "chat":        "message-circle",      # 对话
    "schedule":    "calendar",            # 日程
    "health":      "heart",               # 健康
    "appearance":  "palette",             # 外观
    "update":      "refresh-cw",          # 更新
    "data":        "database",            # 数据
    "settings":    "settings",            # 设置
    "exit":        "log-out",             # 退出
    "about":       "info",                # 关于

    # 功能
    "drink":       "droplet",             # 饮水
    "meal":        "utensils",            # 饮食
    "rest":        "coffee",              # 休息
    "mood":        "smile",               # 心情
    "search":      "search",              # 搜索
    "reminder":    "bell",                # 提醒
    "quiet":       "bell-off",            # 免打扰
    "pause_all":   "pause-circle",        # 暂停所有提醒

    # 状态
    "success":     "check-circle",        # 成功
    "warning":     "alert-triangle",      # 警告
    "error":       "x-circle",            # 错误
    "loading":     "loader",              # 加载中
}
```

##### 7.2 尺寸

| 场景 | 尺寸 |
|------|------|
| 托盘图标 | 16x16px（SVG 渲染为 QPixmap） |
| 导航图标 | 20x20px |
| 通知/状态图标 | 24x24px |
| 设置面板图标 | 20x20px |
| 消息内图标（emoji 替代） | 与文字同高 |

##### 7.3 加载方式

SVG 文件不存在时回退到 Emoji 占位：

```python
def load_icon(name: str, size: int = 20) -> QIcon:
    svg_path = f"ui/resources/icons/{ICON_MAP.get(name, 'circle')}.svg"
    if os.path.exists(svg_path):
        return QIcon(svg_path)
    # 回退：生成 emoji 文字图标
    fallback = {"chat": "💬", "settings": "⚙", "schedule": "📋"}
    return _emoji_icon(fallback.get(name, "●"), size)
```

#### 8. 无障碍最低标准

| 要求 | 实现 |
|------|------|
| 最小字号 `12px` | `Fonts.SIZE_XS` 改为 `12`，`SIZE_SM=13`，`SIZE_MD=14` |
| 最小点击区域 `32x32px` | 关闭按钮、导航项、托盘菜单项均 ≥ `32px` 高度 |
| 键盘可导航设置面板 | Tab 键在表单控件间切换，Enter 确认 |
| 高对比度模式下不依赖颜色 | 桌宠消息用左边框（非纯颜色）区分；成功/危险用图标+文字双重标识 |
| 通知必须包含文字 | 不出现纯图标通知 |
