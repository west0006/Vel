## 二、体验感

### 2.1 ⚠️ 同步 HTTP 调用可能阻塞 UI（重点）

共 **14 处** `requests.*` 调用，`timeout` 3~5 秒：

| 位置 | 用途 | 是否可能在 UI 线程 |
|---|---|---|
| `modules/greeting.py:69,117` | 启动问候获取天气/一言 | ⚠️ 高（问候由启动或定时触发） |
| `modules/health/meal_engine.py:234` | 饮食推荐取天气 | ⚠️ 高 |
| `services/location_service.py:117,166,183,441,444` | IP 定位、天气 | ⚠️ 需核实调用方 |
| `services/llm_service.py:185,224,270` | Ollama 对话 | ✅ 后台线程 |
| `services/memory_service.py:45,53` | 嵌入服务探测 | ✅ 后台线程 |

`AGENTS.md` §4.3 要求「UI 线程单次阻塞不得超过 200ms」—— 上述 `timeout=3s` 的调用一旦落在 UI 线程，就是**界面卡死 3 秒**。

**这是体验问题里确定性最高、影响最直接的一项。**
