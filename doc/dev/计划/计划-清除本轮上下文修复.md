# 计划-清除本轮上下文修复

> **状态**：✅ 完成 ｜ **最后核对**：2026-11-10
> **来源**：用户反馈“清除对话按钮无效”
> **用户确认语义**：只清本轮上下文，保留 `conversation_archive` 历史存档

## 问题

`ui/settings_window.py` 的「清除本轮」按钮确实连接到了 `ChatManager.clear_context()`，但该方法只清：

- `LLMService._history`
- `_turn_count`

没有清 `ChatManager._history_cache`，也没有清对话气泡；设置页 `_refresh_chat()` 读 `get_history()`，缓存为空时又回退到 `conversation_archive` → 列表看起来完全没变化，且没有任何提示。

## 目标

- 清空本轮上下文：LLM 历史、`_history_cache`、对话气泡消息、轮次计数。
- 设置页列表在清除后显示为空；清除后新产生的消息仍可正常显示。
- 明确反馈：弹出提示“本轮上下文已清除，历史存档仍保留”。
- 不删除 `conversation_archive`。

## 非目标

- 不改「数据 → 清除所有数据」。
- 不删除历史存档，不改导出/备份。
- 不改 LLM 降级、记忆召回、摘要逻辑。

## 验收标准

- [x] `clear_context()` 清空 `_history_cache`、`_turn_count`，并调用 `LLMService.clear_history()`。
- [x] 清除后 `get_display_history()` 返回空；`conversation_archive` 行数不变。
- [x] 清除后新增消息只显示新消息，不把旧存档带回列表。
- [x] 设置页「清除本轮」清空气泡、刷新列表并弹出提示。
- [x] 全量回归全绿；代码随 `main.py` 启动加载无异常（按钮点击待用户肉眼确认）。

## 步骤

1. `ChatManager`：新增 `_context_cleared`、`get_display_history()`；`clear_context()` 清缓存并置位。
2. `SettingsWindow`：`_refresh_chat()` 改用 `get_display_history()`；`_clear_context()` 清气泡 + 弹提示。
3. 补集成测试：清上下文保留存档、清后列表为空、新消息只显示新内容。
4. 全量回归 + 真机验证。

## 风险与回滚

| 风险 | 处置 |
|---|---|
| 清后重启列表又显示旧存档 | 这是“只清本轮”的预期：存档未删；清除状态只在本次进程内有效 |
| 清空时正在流式输出 | 极端情况下后续 chunk 可能继续追加；本任务不处理并发流 |
| 误删历史 | 不执行 DELETE，存档保留 |
| 回滚 | 只改 `chat_manager.py`、`settings_window.py` 与测试，可单独 revert |
